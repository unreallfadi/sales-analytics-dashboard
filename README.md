# Sales Analytics Dashboard

An interactive sales analytics dashboard built with **Flask**, **SQLite**, and **Chart.js**.

## Features
-  Real-time KPI cards (Total Revenue, Orders, Customers)
-  Bar chart for top products by revenue
-  Doughnut chart for units sold distribution
-  Detailed product breakdown with visual progress bars

## Tech Stack
- **Backend**: Flask (Python)
- **Database**: SQLite  
- **Frontend**: HTML5, CSS3, JavaScript
- **Charts**: Chart.js
